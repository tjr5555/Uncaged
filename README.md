# Uncaged

## Uncaged is a physics based platformer and adventure game set in a floating world.
### The goal is to fly around and pop balloons by entering portals which lead to unknown worlds. 

---

### Some planned features:
- Seamless loading between portals
- Quest & progression system
- Detailed flight & movement system
- Procedurally generated random worlds
- Original soundtrack created in FL Studio
